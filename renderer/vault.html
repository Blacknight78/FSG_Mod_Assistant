Vault selection help
Plain left-click
Does not change selection. Use it to interact with the row without accidentally selecting mods.
Ctrl + left-click
Toggles one mod on or off. For bulk copying, this selects that mod's newest stored ZIP by default.
Shift + left-click
Selects every mod group between the last selected mod and the mod you clicked.
Alt + left-click
Clears the current selection and selects only the mod you clicked.
Double-click
Shows or hides the stored versions for that mod group. It does not select the mod.
Version checkboxes
After opening a mod group, use the version checkbox when you want to select a specific stored ZIP instead of the newest one.
