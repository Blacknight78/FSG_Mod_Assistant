Tags
No tag state is selected by default, so all mods show until you require or exclude a tag.
How tag filters work
No tag button selected means that tag is ignored and all mods can show.
Must not have hides mods that have that tag.
Must have only shows mods that have that tag.
Match all required tags means a mod needs every required tag. Match any required tag means a mod can have any one of the required tags. Excluded tags always apply after that.

Mod selection help
Plain left-click
Does not change selection. Use it to interact with the row without accidentally selecting mods.
Ctrl + left-click
Toggles one mod on or off without changing the rest of the selected mods.
Shift + left-click
Selects every mod between the last selected mod and the mod you clicked.
Alt + left-click
Clears the current selection and selects only the mod you clicked.
Double-click
Opens the mod details window. It does not select the mod.
